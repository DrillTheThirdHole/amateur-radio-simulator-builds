# Amateur Radio Simulator — test builds

Download the newest release's zip for your system under **Releases**
(`AmateurRadioSimulator-<version>-windows.zip` or `-linux.zip`), unzip it somewhere you own
(e.g. Documents — not Program Files), and run the program inside.

After that the game updates itself: when a new build is out, the main menu offers **Update and restart**.

The other files on each release (`manifest-*.json`, `game-*.zip`, `bin-*.zip`, …) are for the in-game updater.
